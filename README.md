# abrorkulov.uz

Portfolio of Jahongir Abrorkulov, full-stack engineer from Tashkent.

Scrolling flies a camera from the real Earth, with the night side where night is right now, past a
planet for each project, to a working x86 crackme on Pluto, out of the Milky Way and into the deep
field. Everything is rendered live in the browser.

## Stack

React 18, TypeScript and Vite. The world is raw WebGL2. No 3D, animation or CSS library.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck, then production build
npm run preview  # http://localhost:4173
```

`CLAUDE.md` has the architecture, what is real and what is not, and the bugs worth remembering.
