# abrorkulov.uz

Portfolio of Jahongir Abrorkulov, full-stack engineer from Tashkent. From the pixel to the register.

The page is laid out as a descent through the stack: shipped products at the surface, then layers of
abstraction peeling away, down to a working crackme running on an x86 emulator in the browser.

## Stack

React 18, TypeScript and Vite. The hero is raw WebGL2. No animation, 3D or CSS library.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck, then production build
npm run preview  # http://localhost:4173
```

`CLAUDE.md` has the architecture, the design rules and the bugs worth remembering.
